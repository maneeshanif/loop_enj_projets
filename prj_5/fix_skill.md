# Bug Fix Skill v2

## Steps for the Implementer (Maker)
1. Analyze the bug
2. Locate the code
3. Draft a fix
4. Test locally
5. Submit for review

## Reviewer (Checker) Instructions
- PASS - fix correct, no new issues
- FAIL - incomplete, incorrect, or new problems
